REVISION HUB — YEAR 13

Included subjects: Biology, Chemistry, Maths.

Core behaviour:
- Daily task list, no fixed revision times.
- Mon–Sat Anki target of about 60 minutes total, split between Biology and Chemistry.
- Weekly targets: 270 minutes homework per subject and 60 minutes exam questions per subject.
- Tasks, completion, edits, moves, topics, exams and history are stored locally in the browser.
- Weekly history is preserved and recalculated from task data to avoid stale totals.
- Weak topics can influence generated tasks.
- Upcoming exams/deadlines increase subject priority.
- Missed tasks are surfaced separately.
- Direct live Anki syncing is not claimed; normal web apps cannot read a user's Anki collection/review state directly. Manual Anki logging creates a completed Anki task, so it uses the same single progress counter as generated Anki tasks.
- PWA manifest/service worker included. For iPhone Home Screen installation, host the folder over HTTPS, open it in Safari, then Share → Add to Home Screen.

IMPORTANT: The supplied folder is a complete static app. No build step or external library is required.
